# tv-apps

تحديثات تطبيقات التلفزيون (Mi TV Stick):

| التطبيق | الحزمة | الإصدار |
|---|---|---|
| رُكن — الواجهة الرئيسية | `com.mohamed.home` | 5.5 |
| أُفُق — مشغّل IPTV | `com.mohamed.ufuq` | 3.2.1 |

رُكن يقرأ `update.json` ويعرض «تحديث متوفر» في الإعدادات ← تحديث التطبيقات، ثم ينزّل الملف من مجلد `apks/` ويثبّته.

لنشر تحديث: ضع الـ APK الجديد في `apks/` باسم يحمل رقم الإصدار، وارفع `versionCode` و`versionName` و`url` في `update.json`.
